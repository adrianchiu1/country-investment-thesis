Word round-trip prototype

Proves that a single-file page, with no libraries, can write a real .docx from an economy’s YAML and read a human-edited one back — including the three structural edits a researcher will actually make: adding, deleting and reprioritising. Open this file in Edge or Chrome; the tests run on load.

What to check first. Click Download United States.docx and open it in Word. Then:
  • type into one of the italic “Click here and type a new issue” boxes — that is how an issue is added;
  • select everything inside one signpost’s boxes and delete it — that is how one is retired;
  • drag an issue’s box above its neighbour — that is how they are reprioritised;
  • save, and confirm the grey content-control boxes are still there.
That last point is the one assumption these tests cannot verify without Word.
