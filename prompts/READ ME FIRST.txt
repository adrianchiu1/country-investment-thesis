HOW TO UPDATE AN ECONOMY WITH ADA
=================================

Ada is the firm's chatbot in the browser. You give it a prompt and one economy
file, work through changes with it, and bring its answer back into the page.
One economy per conversation.

The easy way: open EDITOR-country-investment-thesis.html, select the economy,
and click the "Ada prompt" button next to Import. Its "Copy prompt + file"
button puts the prompt AND the economy's current file on your clipboard in
one go, so you never need to find anything in the folder. The steps below
assume you did that; the folder route is given as a fallback.

Fallback, if the page is not available: in this synced folder,
  1. The prompt:  prompts\Ada prompt - update an economy.txt
     Double-click it (it opens in Notepad), press Ctrl+A then Ctrl+C.
  2. The economy file:  data\<economy>.yaml, for example data\eurozone.yaml
     Open it the same way and copy it, or attach it to Ada.
Never edit or move the files in data\ by hand.

STEPS
-----

  1. Open Ada in your browser and start a new conversation.

  2. Paste (Ctrl+V) into the message box: the prompt and the economy file
     arrive together. Do not send yet.

  3. Check the end of what you pasted shows the economy file (it starts with
     "id:" and ends with the implications block). If you copied only the
     prompt, click "Copy file" in the page and paste it below the prompt.

  4. Send. Ada asks for your name if it does not know it, then asks how you
     want to work:
       - Review Mode: Ada reviews the thesis with you, three items at a
         time, page by page (Drivers, Signposts, Implications), asking
         whether each still holds given the latest evidence and your
         latest judgement. You pick which to review.
       - Discuss Mode: you set the topic. Ada discusses it with you as a
         friendly junior macro strategist: frames the issue, brings the
         numbers and a view, floats the decisions for you, refines
         wording with you.
       - Incorporate Mode: you attach or paste a document (your own note,
         meeting notes, a report). Ada extracts its key points and
         incorporates them into the thesis, grounded in the document only.
     Reply "Review", "Discuss" or "Incorporate". You can switch later by
     saying "switch to ...".

  5. Whatever the mode, a change only enters the file after Ada shows the
     current wording and the proposed wording and you reply "approve".
     Say "approve" only when the wording is exactly what you want;
     otherwise say what to change.

  6. In Review and Incorporate Mode, Ada offers three more items or moving
     on to the next page. In Discuss Mode, Ada ends each topic by asking
     whether to keep discussing it, discuss something else, or suggest
     what to look at next.

  7. At the end Ada shows the full list for a final approval and hands back
     the whole file: as a downloadable <economy>.yaml where Ada can attach
     files, and always as a code block. If you download it, save it anywhere
     convenient such as Downloads. Do NOT save it into the data folder.

  8. Open EDITOR-country-investment-thesis.html from this folder, select the
     economy and click Import. Either choose the downloaded file, or copy
     Ada's code block and paste it straight into the Import box (no Notepad
     needed). Review the changes and click "Apply import". The change log
     records everything, including Ada's change note.

  9. If Ada's change note lists matrix suggestions, click Edit and set the
     arrows on the Investment implications page yourself.

You can say "stop" or "checkpoint" to Ada at any time; it will explain the
options. If you get stuck, the researcher does not need to fix anything in the
files by hand: cancel the import and ask for help.
